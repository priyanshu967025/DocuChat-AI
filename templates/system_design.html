🔄 RAG Data Flow Pipeline

End-to-end pipeline from PDF upload to AI-generated answer delivery.

1 📤 PDF Upload User uploads via browser or REST API
2 📄 Text Extract PyPDF2 + OCR fallback (Tesseract)
3 ✂️ Chunking 500-word segments, 50-word overlap
4 🧮 Vectorize TF-IDF + FAISS Index build
5 💬 User Query Natural language question
6 🔎 Retrieval FAISS cosine similarity + phrase boost
7 🧠 LLM Generate Qwen3 → Gemini → Local Synth
8 ✅ Response Structured Markdown answer

Key Architectural Decisions
  • Chunking Overlap (50 words): Prevents information loss at segment boundaries during TF-IDF vectorization.
  • FAISS FlatIP Index: Inner-product similarity on L2-normalized vectors provides exact cosine retrieval at scale.
  • Phrase Boosting (+3.0): Exact query phrase match in a chunk boosts its retrieval score, improving precision for follow-up questions.
  • Context-Aware Follow-Up: Short follow-up queries are concatenated with the previous user question for better retrieval.
  • Multi-DB Support: DB_ENGINE=postgres|sqlite env switch. SQLite for dev, PostgreSQL for production — zero code change.
  • Celery + Redis Async: Heavy OCR & vectorization offloaded to background workers, keeping HTTP response fast (<200ms).
  • WhiteNoise Static CDN: Compressed, hashed static files served directly from Django without external Nginx dependency.
  • Graceful LLM Degradation: If all external APIs are down, the local synthesis engine guarantees response quality with zero latency.
